# edu-instructor-match

K·S·A·C·L 5축 적합도 엔진. 요구 프로파일과 후보 프로파일을 받아 적합도와 그 근거를 낸다.
산식은 도메인에 중립이고, 쓰는 쪽이 두 프로파일을 만들어 넘긴다.


## 바꾸지 않는 규율 넷

1. 검증한 수치만 적는다 — 가중치는 조정 가능한 기본값이며 검증하지 못한 계수를 상수로 박지 않는다
2. **설명 없는 점수를 반환하지 않는다** — 모든 산출은 축별 기여도와 사유를 동반한다
3. 보호속성과 그 대리변수는 입력에 없다
4. LLM 을 쓰지 않는다 — 규칙 기반이 설명가능성이 가장 높고 비용이 0이다

## 쓰는 쪽

교육 발주 축의 어댑터는 `lib/matching/instructor.ts` 이고 통제 어휘는 `lib/matching/vocab.ts` 다.


⛔두 앱의 데이터를 조인하지 않는다. 공용하는 것은 산식뿐이다.

## 시험

```
npx tsx lib/engine/engine.test.ts
```
