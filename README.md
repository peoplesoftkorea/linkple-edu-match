# 강사 위촉·매칭 플랫폼

기업 교육 발주와 강사를 잇는 플랫폼이다. 발주사가 교육을 의뢰하면 운영자가 과정을 설계하고
강사를 위촉한다. 강사 선정은 5축 적합도 산식으로 후보를 산출해 운영자에게 근거와 함께 제시한다.

## 무엇이 어려운 문제인가

강사 선정은 「주제가 맞는 사람 찾기」가 아니다. 같은 주제라도 강의 방식(강의·워크숍·실습)과
대상 층(최고경영자·실무자)이 맞지 않으면 과정이 실패한다. 그리고 **후보를 떨어뜨린 이유를
말하지 못하면 그 정렬은 쓸 수 없다.**

그래서 이 시스템은 점수만 내지 않는다. 축별 기여도와 사유를 함께 낸다.

## 5축

| 축 | 재는 것 | 입력 |
|---|---|---|
| K | 강의 주제 적합 | 전문 분야 ↔ 발주 주제 |
| S | 강의 방식 적합 | 수행 가능 방식 ↔ 요구 방식 |
| A | 강의 경력·대상 | 경력 연수·대상 층 ↔ 요구 수준 |
| C | 교육 지향 적합 | 가치 프로파일 상관 |
| L | 운영 조건 | **이 제품에서는 쓰지 않는다**(아래 참조) |

C축은 **가치축 3개 미만이면 `null`** 을 반환한다. 측정하지 못한 것을 0으로 바꾸지 않는다.

## 지키는 규율 넷

1. 검증한 수치만 적는다 — 가중치는 조정 가능한 기본값이며 검증하지 못한 계수를 상수로 박지 않는다
2. **설명 없는 점수를 반환하지 않는다** — DB 제약으로 집행한다. 축별 근거가 비면 행이 들어가지 않는다
3. 보호속성과 그 대리변수는 입력에 없다
4. 매칭에 LLM 을 쓰지 않는다 — 규칙 기반이 설명가능성이 가장 높고 비용이 0이다

## 구조

```
lib/engine/      5축 적합도 산식 — 도메인에 중립이다
lib/matching/    교육 발주 ↔ 강사 어댑터 + 통제 어휘 사전
supabase/        스키마와 그 제약 검증
tools/           매칭 실측 · 어휘 검사 · 명부 표준화 · ERD 생성
docs/            ERD · 자율 결정 기록 · 명부 양식
```

## 돌려 보기

```bash
npx tsx lib/engine/engine.test.ts        # 산식 검증(경계값 · 반사실 공정성)
npx tsx tools/import-roster.mts --selftest   # 명부 표준화 자가시험
```

운영 데이터가 필요한 도구(`matchprobe`·`vocabguard`)는 DB 접속이 있어야 돌아간다.
`.env.example` 을 복사해 값을 채운다.
