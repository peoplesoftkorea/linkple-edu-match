# 강사 명부 — 받는 칸과 표준화 규칙

양식 = `instructor-roster-template.csv`(첫 줄 헤더 고정 · 둘째 줄은 예시이며 지우고 쓴다).

## 1. 칸 — 필수 셋과 그 밖

| 칸 | 구분 | 쓰임 | 비면 생기는 일 |
|---|---|---|---|
| 성명 | **필수** | 식별 | 적재되지 않는다 |
| 전문분야 | **필수** | K축(강의 주제 적합) | 매칭이 서지 않는다 |
| 연락가능 | **필수** | 후보 포함 여부 | 기본값 「가능」으로 둔다 |
| 강의이력요약 | 권장 | A축 — 여기서 **경력 연수와 대상 층을 추출**한다 | 경력 요건을 적용하지 못한다 |
| 출강지역 | 권장 | 권역 하드 필터 | 권역을 지정한 발주에서 전부 제외된다 |
| 희망단가 | 선택 | 회차 단가 | 정산 설계에서 다시 묻는다 |
| 강의방식 | 선택 | S축 | 0점 — **당사 PM 이 과정 설계 때 채워도 된다** |
| 대상층 | 선택 | A축 | 이력 요약에서 추출을 시도한다 |
| 교육지향 | 선택 | C축 — `키:값` 쌍 3개 이상 | 「측정 불가」로 남는다(0 이 아니다) |

★**필수 셋만 받아도 적재된다.** 칸을 늘려 다시 청하면 수령이 늦어진다.
★교육 지향은 명부 단계에서 받기 어렵다 — **위촉 협의 때 받는다.**

## 2. 표준화 — 자유 표기를 사전 값으로 옮긴다

정본은 `lib/matching/vocab.ts` 이고, 임포터가 그 파일을 읽어 변환한다.

| 받은 말 | 저장되는 값 |
|---|---|
| 브랜드 · 브랜딩 | 브랜드전략 |
| 디지털전환 · DX · AX | AXDX |
| 디지털전환·클라우드 | AXDX + 클라우드 (한 칸이 두 값) |
| 서울 · 경기 · 인천 | 수도권 |
| 대전 · 충남 · 강원 | 충청강원 |
| 부산 · 대구 · 울산 · 경남 | 영남 |
| 「마케팅 임원 15년」 | 경력 15년 · 대상 층 「임원」 |

⛔사전에 대응이 없는 말은 **매핑하지 않고 이탈로 남긴다.** 억지로 붙이면 틀린 매칭이 된다.
이탈은 임포터가 목록으로 보고하며, 사전에 넣을 값이면 `vocab.ts` 에 먼저 추가한다.

## 3. 적재

```
npx tsx tools/import-roster.mts --csv <파일> --source "<출처>"   # 미리보기
npx tsx tools/import-roster.mts --csv <파일> --source "<출처>" --sql > /tmp/roster.sql
kps-migrate.sh /tmp/roster.sql core
```

⛔임포터가 DB 에 직접 쓰지 않는다 — SQL 을 내고 적용은 사람이 한다.
★`--source` 는 반드시 지정한다. 명부를 교체하거나 되돌릴 때 **이 값 하나로 구분**한다.
